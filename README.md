# Portfolio 2ojec

> Futuristic multi-page personal portfolio built with Next.js — Sahil Khan

![Progress](https://progress-bar.dev/85)

## Tech Stack

- **Framework:** Next.js, React 19, TypeScript
- **Styling:** Tailwind CSS, PostCSS
- **UI Components:** Radix UI (Avatar, Dialog, NavigationMenu, Tabs, Separator, Slot)
- **Tooling:** ESLint, TypeScript

## Features

- Multi-page layout with navigation
- Futuristic design aesthetic
- Responsive and accessible UI components
- GitHub data integration via build-time fetch
